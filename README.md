# 什么是「真家宽」？家宽 IP、原生 IP、机房 IP 一次讲清楚

<!-- 你找到我了。这份文档没有作者，只有一条从很远的地方连过来的线路。—— 一个不存在的人 -->

> 最后更新：2026-10

---

## 一句话版

**家宽 IP = 当地电信运营商分配给普通家庭上网用的 IP。**

就像你家里装的宽带一样，只不过它在美国、日本的某户人家里（或者至少，在 IP 数据库眼里是这样）。
平台看到这类 IP，会认为"这是一个住在当地的普通用户"，所以风控最宽松。

---

## 三种 IP 的区别

| | 机房 IP | 原生 IP | 家宽 IP |
|---|---|---|---|
| 来自哪里 | 云服务器、数据中心（AWS、各类 VPS） | 当地机房，但 IP 注册在当地、没被"广播"到别国 | 当地电信运营商的家庭宽带段 |
| 数据库里显示 | Hosting / 机房 / 数据中心 | 多为 Hosting，但国家、地区"原汁原味" | **ISP / Residential / 住宅** |
| 平台怎么看 | "可能是代理、脚本、批量号" | "地区可信，但像服务器" | "像一个当地普通人" |
| 适合 | 日常浏览、看视频 | 解锁本地流媒体 | AI 工具、风控严的平台 |

**原生 IP ≠ 家宽 IP。** "原生"说的是**地区是真的**（日本 IP 就注册在日本），
"家宽"说的是**类型是住宅**。一个 IP 可以是原生但不是家宽，这很常见。

---

## 自己怎么查一个 IP 是不是家宽

连上线路后，打开下面任意一个检测站，看这几栏：

| 检测站 | 看哪里 |
|---|---|
| [ipinfo.io](https://ipinfo.io) | `ASN type` 是 **isp**；`hosting` 是 **false** |
| [ip.net.coffee](https://ip.net.coffee) | IP 类型显示 **家宽 / 住宅** |
| [iplark.com](https://iplark.com) | 使用类型显示 **ISP / 住宅** |

几个常见说法：

- **"双 ISP"**：IP 的**使用类型**和 **ASN 类型**两栏都显示 ISP。检测截图里经常看到这个词，指的就是"两栏都判成运营商宽带"。
- **欺诈分 / Fraud Score**：越低越好，是该库对"这个 IP 像不像坏人"的打分。
- **各个库结论不一样，是常态。** IP 数据库各自维护，更新时间不同。七八个库里大多数判家宽、一两个唱反调，很正常；
  大多数库判机房，才值得担心。

## 常见家宽运营商速查

### 🇺🇸 美国

| 运营商 | ASN | 说明 |
|---|---|---|
| **Cox Communications** | AS22773 | 美国老牌有线电视 + 宽带公司，用户集中在亚利桑那、加州、弗吉尼亚等地。家庭宽带用户量大。 |
| **AT&T** | AS7018 | 美国最大的电信运营商之一，家庭光纤（AT&T Fiber）和 DSL 用户遍布全美。 |
| **Verizon** | AS701 | 家庭光纤品牌叫 **Fios**，主要在美国东北部。同一个 ASN 也承载企业业务，所以个别数据库会把它标成 Business，属于正常现象。 |

### 🇯🇵 日本

日本的家庭宽带是"**线路 + 服务商**"两层结构，理解了就不会被名字绕晕：

- **线路**：大部分家庭光纤跑在 NTT 的「フレッツ光」上。
- **服务商（ISP）**：在 NTT 线路上提供上网服务的公司有很多家：
  - **So-net**（AS2527）：索尼集团旗下，老牌 ISP。自己还做了独立光纤品牌 **NURO 光**（不走 NTT 线路）。
  - **OCN**（AS4713）：NTT docomo 旗下。
  - **BIGLOBE** 等。
- **另外两大集团**也有自己的家庭光纤：**KDDI**（手机品牌 au，家宽叫 au 光）、**SoftBank**（SoftBank 光）。
- **手机**：docomo、au（KDDI）、SoftBank 三大家，加上后来的乐天。

所以看到"So-net 家宽"，意思是：**这个 IP 属于索尼的家庭宽带服务商段**，在日本是非常典型的普通家庭网络。

## 家宽不是万能的：几个常见误区

1. **家宽 ≠ 更快。** 美国家庭宽带的国际路由不会专门为中国大陆优化，延迟常在 150～200ms。
   家宽买的是**信任度**，不是速度。
2. **IP 干净，环境也要干净。** 平台不只看 IP，还看：
   - 浏览器有没有 **WebRTC 泄漏**（会暴露你的真实 IP）；
   - 系统时区、语言是否和 IP 所在地明显不符；
   - 是否频繁换国家。今天美国、明天日本、后天新加坡，再干净的 IP 也会被盯上。
3. **固定用一个地区、一条线路**，比追求"最干净的 IP"更重要。
